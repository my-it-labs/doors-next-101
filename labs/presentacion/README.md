# Presentación — IBM DOORS Next

Presentación para abrir la formación: **qué es** el producto, **para qué sirve** y **por qué lo usamos**. Los frames están capturados del vídeo de IBM Business Partner (Servisys): https://www.youtube.com/watch?v=CG5LIOBnuA4

## Cómo presentar

Abre `presentacion.html` en cualquier navegador (no necesita internet).

| Tecla | Acción |
|-------|--------|
| `→` / `Espacio` / clic derecho | Siguiente |
| `←` / clic izquierdo | Anterior |
| `F` | Pantalla completa |
| `N` | Mostrar/ocultar notas del ponente |
| `Inicio` / `Fin` | Primera / última diapositiva |

## Estructura (18 diapositivas, ~5 min)

1. **Portada** — IBM DOORS Next
2. ¿Sabías que…? (gancho)
3. Project failure (consecuencia)
4. Requisitos dispersos *(problema 1)*
5. Sin trazabilidad vas a ciegas *(problema 2)*
6. Equipos desalineados *(problema 3)*
7. Herramientas desconectadas *(problema 4)*
8. Equipos distribuidos *(agravante)*
9. ¿Cuál es el coste? *(la factura)*
10. Usa la herramienta adecuada *(puente)*
11. **La solución: IBM DOORS Next**
12. Una única fuente de verdad *(beneficio 1)*
13. De la necesidad al requisito *(beneficio 2)*
14. Trazabilidad extremo a extremo *(beneficio 3)*
15. Enlaces entre artefactos *(beneficio 3)*
16. Edición colaborativa y versionado *(beneficio 4)*
17. Dashboards e informes en vivo *(beneficio 5)*
18. **Cierre: ¿por qué lo usamos?**

> Narrativa clásica: **problema → consecuencias → coste → solución → beneficios → cierre**. Cada diapositiva incluye notas del ponente (tecla `N`).
