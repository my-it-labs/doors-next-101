# IBM DOORS Next 101

[Siguiente página →](labs/M01-preparar-entorno/README.md)

Formación **100 % práctica**.

## Temario

Curso introductorio a **IBM DOORS Next** para gestionar requisitos de principio a fin: desde
montar el entorno hasta exportar informes para las partes interesadas. Cada módulo combina
**teoría breve**, **demostración guiada** y **laboratorio**.

| Módulo | Contenidos | Labs |
|--------|------------|------|
| **M01** · Preparar el entorno | Docker / Codespaces, acceso a DOORS Next, área de proyecto, plantilla, permisos de autoría | [M01-02](labs/M01-preparar-entorno/M01-02-gestionar-permisos.md) |
| **M02** · Fundamentos de requisitos | Tipos de requisito, atributos de calidad, ciclo en V, artefacto como unidad de información | [M02-01](labs/M02-fundamentos-requisitos/M02-01-clasificar-requisitos.md) |
| **M03** · Navegación y estructura | Artefactos, módulos y colecciones; jerarquía, numeración e ID; vistas y filtros | [M03-01](labs/M03-navegacion-estructura/M03-01-navegar-y-vistas.md) |
| **M04** · Creación y mantenimiento | Crear módulos, encabezados y requisitos; indentar; tipos, atributos y estados (flujo de trabajo) | [M04-01](labs/M04-creacion-mantenimiento/M04-01-crear-modulo.md), [M04-02](labs/M04-creacion-mantenimiento/M04-02-atributos-estados.md) |
| **M05** · Trazabilidad operativa | Enlaces tipados, matrices de trazabilidad, análisis de impacto | [M05-01](labs/M05-trazabilidad/M05-01-enlaces-y-trazabilidad.md) |
| **M06** · Control de cambios | Líneas base (baselines), comparación entre versiones, historial y auditoría | [M06-01](labs/M06-control-cambios/M06-01-baselines-e-historial.md) |
| **M07** · Informes y comunicación | Exportar a Word, CSV y PDF; vistas orientadas a informes y stakeholders | [M07-01](labs/M07-informes-comunicacion/M07-01-exportar-e-informes.md) |

**Al terminar podrás:**

- Trabajar en tu propio proyecto de DOORS Next con permisos de autoría.
- Clasificar requisitos y reconocerlos como artefactos con atributos.
- Navegar, crear y mantener módulos con jerarquía, estados y flujo de trabajo.
- Establecer trazabilidad con enlaces tipados y evaluar el impacto de un cambio.
- Congelar hitos con líneas base y comparar evoluciones.
- Exportar la información en formatos listos para compartir.

**Material complementario:** [Presentación introductoria](labs/presentacion/README.md).
